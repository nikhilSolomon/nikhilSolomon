- 🍎 Building **macOS applications** at Zoho since 2023 with AppKit, SwiftUI and XCTest.
- 🔍 Working on **search & indexing** pipelines: document parsing, OCR, attachment processing, Apache Lucene and Tika.
- ⚡ Making things fast: CPU, memory and execution-time **profiling** with Xcode Instruments, then fixing the real hotspot.
- 🧪 **UI test automation** with XCTest plus pixel-level image comparison for visual regression checks.

## 💡 How I work

| Principle | In practice |
| --- | --- |
| Understand before building | Reproduce the problem, read the code path, then design the fix |
| Measure, do not guess | Profiler traces and benchmarks before and after every performance change |
| Automate the boring parts | Test infrastructure, CI/CD, scripts for anything done twice |
| Build for the long run | Maintainable, testable code with regression checks that keep it fixed |
